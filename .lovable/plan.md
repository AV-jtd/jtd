# Карточка клиента (CRM)

Сейчас данные о клиенте размазаны: короткая правая панель `ClientContextPanel` (в чате) + строки списка `CrmClientsList`. Цель — единая **карточка клиента** как «профиль»: шапка с лого, контакты, команда, метрики, задачи, протоколы, лента активности. Всё, чего ещё нет в данных, показываем аккуратными плейсхолдерами, чтобы каркас был готов заранее.

## Что уже есть в БД (выводим реально)

Таблица `clients`: `name, logo_url, contact_name, phone, email, city, manager_id` + теги `rank_tag_id / territory_tag_id / retail_type_tag_id / tag_id`. Связи: `client_assignments` (команда), `tasks.client_id` (задачи, сейчас 28), CRM-комната `task_groups(project_type='crm_client')` с чатом `group_messages`.

Состояние данных: лого есть у 1 из 11, телефон/почта почти пустые → плейсхолдеры оправданы.

## Структура карточки

```text
┌───────────────────────────────────────────┐
│ [Лого ✎]  Название клиента                 │  ← смена лого как в шапке проекта/протокола
│           [Ранг A] [Территория] [Тип]      │
├───────────────────────────────────────────┤
│ Контакты (инлайн-редактирование)           │
│  👤 Контактное лицо   ✎                    │
│  📞 Телефон           ✎                    │
│  ✉️ Email             ✎                    │
│  📍 Город             ✎                    │
├───────────────────────────────────────────┤
│ Метрики: В работе · Просрочено · Готово    │
├───────────────────────────────────────────┤
│ Команда по клиенту (ответственный + assign)│
├───────────────────────────────────────────┤
│ Задачи клиента (TaskItem, раскрытие)       │
├───────────────────────────────────────────┤
│ Протоколы / встречи  ← derive, пока пусто  │
├───────────────────────────────────────────┤
│ Лента активности (сообщения CRM-комнаты)   │
├───────────────────────────────────────────┤
│ Плейсхолдеры на будущее (см. ниже)         │
└───────────────────────────────────────────┘
```

## Реализуем сейчас (на реальных данных)

1. **Смена лого** — кнопка-карандаш на аватаре, загрузка в Storage (новый bucket `client-logos`, public, по образцу `protocol-logos` в `ProtocolHeader`), запись `clients.logo_url`. Подхватится везде через `ClientAvatar` (sidebar чатов, список CRM, шапки).
2. **Инлайн-редактирование контактов** — `contact_name / phone / email / city` редактируются прямо в карточке (по образцу полей в карточке задачи), мутация `update clients`.
3. **Теги-пиллы** — ранг/территория/тип/город как бейджи (ранг уже цветной).
4. **Метрики + задачи** — переиспользуем расчёт open/overdue/completed и рендер через `TaskItem` (единый воркфлоу задач, раскрытие на месте — как в комнате клиента).
5. **Команда** — `client_assignments` + ответственный (уже есть).
6. **Лента активности** — последние сообщения из CRM-комнаты клиента (`group_messages` по `group_id`), компактным списком; ссылка «Открыть чат».

## Связано структурно, но данных пока нет → пустое состояние

- **Протоколы/встречи**: путь `tasks.source_protocol_id` у задач с `client_id`. Сейчас пересечения = 0 (протокольные задачи ещё не привязаны к клиентам через триаж). Секция рендерится с заглушкой «Пока нет встреч по клиенту» и автоматически наполнится, когда триаж проставит связи.
- **Этап воронки**: можно достать из шагов CRM-задачи воронки (subtasks) — выведем бейдж текущего этапа, если задача воронки найдена.

## Плейсхолдеры на будущее (каркас + «скоро»)

Секции с приглушённым видом и подписью «появится позже», без обращения к несуществующим полям:
- Несколько контактных лиц / роли (ЛПР, закупщик)
- Сделки / выручка / план-факт
- Документы и файлы по клиенту
- Адрес + карта
- История взаимодействий (звонки/письма/визиты)
- Связанные бренды / категории продуктов
- Заметки по клиенту

## Где показываем

- Расширяем `ClientContextPanel` → полноценная карточка, используется в правой панели чата (`ChatFullscreen`) и открывается из списка `CrmClientsList` (клик по клиенту).
- Мобильно: та же карточка во вкладке «Инфо» (уже есть `mobilePane="info"`).

## Технические детали

- Новый Storage bucket `client-logos` (public) + политики — миграция.
- Хук карточки расширяем (контакты, лента, протоколы-derive); мутации `updateClientField` и `uploadClientLogo` с инвалидацией `client_context`, `crm_clients`, `chat_rooms`.
- Переиспользуем: `ClientAvatar`, `TaskItem`, `AssigneePicker`, паттерн загрузки лого из `ProtocolHeader`.
- Новый memory-стрим `streams/crm-client-card` с описанием каркаса и плейсхолдеров.
