Страница протокола (`/protocols/:id`) на мобиле (<md, 768px) использует адаптивный режим:

- **Список строк**: вместо горизонтально-скроллируемой таблицы рендерится вертикальный стек карточек (`ProtocolMobileRow`). Карточка показывает: №, чекбокс, заголовок, и три чипа — ответственный · срок · статус. Тап по карточке открывает Bottom Sheet с полным `TaskItem` (`initialOpen`, `sortable={false}`) — те же возможности, что и в обычных списках задач (шаги, теги, файлы, чат, AI).
- **Создание строки**: плавающая кнопка `+` в правом нижнем углу (`fixed bottom-6 right-5`, размер 56px, primary tone). Открывает Bottom Sheet с textarea «Что обсудили / о чём договорились…». Метаданные (ответственный, срок, статус) задаются после создания через карточку.
- **Внутренний блок (красный)**: на мобиле свёрнут по умолчанию (`sectionOpen = !isMobile`). Header стал кнопкой со стрелкой ChevronDown/Right + бейджем-счётчиком внутренних задач рядом с заголовком. Внутри развёрнутой внешней строки (compact mode) блок остаётся раскрытым.
- **Десктоп**: таблица и inline-add-строка показываются через `hidden md:block`; мобильный список и FAB — `md:hidden`. Логика данных, фильтров и сортировки общая для обоих режимов.
