---
name: Protocol Topic ↔ Project auto-link
description: Тема в протоколе автоматически связывается с одноимённым проектом (task_group.linked_tag_id), отображается с иконкой 📁.
type: feature
---

В колонке «Тема» строки протокола (`TopicCell`) тема — это тег категории `event_topic`. При создании новой темы через `useCreateEventTopic`:

1. Ищется/создаётся системная категория `tag_categories.system_key='event_topic'` пользователя.
2. Создаётся тег (или используется существующий с тем же именем).
3. **Авто-привязка**: ищется активный (`closed_at IS NULL`) проект `task_groups` пользователя с таким же именем (case-insensitive). Если найден и у него ещё нет `linked_tag_id` — тег записывается в `linked_tag_id`.
4. Возвращается `{ id, name, linkedGroupId }`. UI показывает toast «Тема привязана к проекту», если связь установлена.

В UI темы, у которых тег = `linked_tag_id` какого-либо проекта, отображаются с иконкой `Folder` (lucide) вместо цветной точки — и в кнопке-триггере, и в списке выбора. Это значит, что фильтрация по теме автоматически подхватит весь контекст проекта (через существующую логику `useTasksFiltered` по linked tags).
