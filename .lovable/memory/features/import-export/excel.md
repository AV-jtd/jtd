# Импорт/Экспорт Excel

## Smart Import (SmartImportDialog)

Диалог поддерживает импорт любых .xlsx файлов с авто-маппингом колонок через AI (`ai-assistant` action `map_columns`).

### Поддерживаемые поля для маппинга

- **title** — название задачи (обязательно)
- **description** — описание / примечание
- **external_ref** — внешний номер задачи (`№ п/п`). Хранится в `tasks.external_ref` для трассируемости и повторных импортов.
- **topic** — тема / блок вопросов. Автоматически создаёт тег с этим именем и привязывает к задаче (третий уровень группировки сверх project/subproject).
- **start_at** — дата постановки
- **deadline** — ПЛАНОВАЯ дата исполнения
- **completed_at** — ФАКТИЧЕСКАЯ дата закрытия. Если заполнена → задача автоматически создаётся как `is_completed: true` с этой датой. AI обучен НЕ путать с deadline.
- **is_completed** — текстовый статус выполнения («в срок», «выполнено», «готово», «✓»). Триггерит автозакрытие.
- **priority** — 1-3
- **status** — статус (текст)
- **assigned_to** — ОДИН основной ответственный (поиск по display_name/email/username)
- **participants_informed** — мульти, разделители: `,` `;` `/` ` и `. Создаёт записи в `task_participants` с ролью `informed`.
- **participants_support** — то же, роль `support`. RACI-модель.
- **tags** — теги через `;`
- **subtasks** — шаги через `;`
- **project / subproject / type** — иерархия

### Правила парсинга

1. Пустые значения (`нет`, `—`, `-`, `н/д`, `n/a`) трактуются как null.
2. Даты: ISO `YYYY-MM-DD`, а также `DD.MM.YYYY` / `DD/MM/YYYY` / `DD-MM-YYYY` (двузначный год → 20XX).
3. Done-статус определяется по словам: done, выполнено, готово, закрыто, ✓, в срок.
4. Участники не дублируются с `assigned_to`.

### UI подсказки

- При `confidence < 0.7` строка маппинга подсвечивается **янтарным** с пометкой «проверить» и янтарной рамкой селектора.
- При `confidence >= 0.8` — зелёная галочка справа.

### Поток черновика

См. [protocol-draft-publish](mem://features/protocol-draft-publish). Импорт протокола создаёт `task_groups.draft_status='draft'` и все задачи `is_draft=true`. Уведомления НЕ рассылаются. Публикация — на странице протокола.
