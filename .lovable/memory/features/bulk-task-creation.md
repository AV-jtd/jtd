Реализована система массового создания задач через универсальный диалог (BulkTaskDialog). Три вкладки:
1. «ИИ-генерация» — анализирует контекст проекта (few-shot learning) и предлагает структурированный план.
2. «Голос» — голосовая диктовка через Web Speech API браузера (useSpeechRecognition, ru-RU, без бэкенда/ключей; авто-рестарт сессии на onend). Переиспользует AiTab с voiceMode: распознанная речь падает в prompt, далее ИИ-генерация умно резолвит ответственных и сроки. Fallback-сообщение, если браузер не поддерживает (Safari/iOS ограничены).
3. «Текстовый список» — вставка списка строк, парсинг через parseQuickTask (@имя, до DD.MM, +Nд, !).

Функция доступна глобально в «Все задачи», в CRM-воронке (Inbox) и внутри проектов. Кнопка с иконкой Layers + Sparkles. При создании из «Все задачи» задачи попадают в Inbox.
