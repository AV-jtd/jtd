# CRM-коммуникация через внутренний командный чат (концепт)

**Идея (от Артёма):** построить CRM-работу вокруг внутреннего чата команды. **ВАЖНО: чат НЕ с клиентом**, а **внутренний чат команды ПРО клиента** — рабочая комната, где менеджеры/аналитики/смежные отделы обсуждают клиента и прямо из переписки заводят задачи, поручения и фиксируют показатели. **1 клиент = 1 рабочая комната команды**, возможно с вкладками. В сайдбарах — команда по клиенту, основные задачи, показатели, поручения, документы.

**Принцип:** end-to-end сценарий JTD по клиенту в одном окне. Протокол → задача → поручение → показатель собираются в единую ленту внутренней дискуссии команды (system-карточки, по аналогии с task-created карточками в ProjectChat).

**Оформление наследует реальный чат приложения (ProjectChat), а НЕ мессенджер «пузырями»:**
- строки сообщений: аватар-инициалы (ChatAvatar) + имя + время + текст, без them/me bubbles;
- системные события (Создана задача / Поручение / Показатель / Протокол) — карточки-разделители в ленте (горизонтальная линия + центральная пилюля с иконкой), как CreatedTaskCard;
- hover-действия (создать задачу, ответить), @упоминания коллег, /команды в композере (/задача, /поручение);
- все цвета через семантические токены (tag-blue/purple/green/orange, primary, muted).

**Макет (отдельная верстка):** `/dev/crm-chat` — `src/pages/dev/CrmChatDemo.tsx` (фейковые данные, ничего не пишет в БД). Трёхпанельный лейаут:
- **Левая панель:** список рабочих комнат = клиенты (эмодзи, ранг A/B/C, стадия воронки, последнее сообщение с автором, стек аватаров команды + «N в команде», непрочитанные).
- **Центр:** шапка клиента + аватары команды по клиенту + вкладки **Обсуждение / Задачи / Показатели / Поручения**. В «Обсуждении» — внутренняя переписка команды + system-карточки.
- **Правый сайдбар:** карточка клиента, контакты, **Команда по клиенту** (роли: ответственный/аналитик/логистика), прогресс по воронке, плитки показателей, основные задачи, поручения, документы.

**Связь с существующим:** переиспользует данные CRM (`clients`: territory/rank/retail_type/manager, воронка CRM_STAGES kp→samples→os→negotiation→shipping) и паттерн чата (`group_messages`, ProjectChat system-карточки, delegation 1 уровень, task_participants как «команда по клиенту»).

**Статус:** реализуем поэтапно. **Цель — вариант C** (комната клиента = центральная лента + system-карточки задач/протоколов/показателей, вкладки, сайдбары). **Первым шагом сделан вариант A (унификация):**

- комната клиента = единственный дом переписки (`task_groups.project_type='crm_client'` + `client_id`, сообщения в `group_messages`);
- **partial UNIQUE index** `(client_id) WHERE project_type='crm_client'` — у клиента не может быть двух комнат; `useEnsureClientRoom` ловит код `23505` и перечитывает существующую;
- одноразовый перенос: переписка по клиенту, лежавшая в чате CRM-задачи воронки (`task_comments kind='message'`), перенесена в `group_messages` комнаты клиента (выполнено для «АЗС Лукойл»: 12 сообщений; логи kind='log' остались в задаче);
- вход в комнату из CRM: кнопка «Чат клиента» (MessageCircle) в `CrmClientsList` → `ensureRoom` → `/chat/:groupId`.

Осталось до C: агрегация событий задач/протоколов system-карточками в ленту комнаты, вкладки Обсуждение/Задачи/Показатели/Поручения, правый сайдбар по клиенту.
