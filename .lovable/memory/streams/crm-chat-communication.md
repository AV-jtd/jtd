# CRM-коммуникация через внутренний чат (концепт)

**Идея (от Артёма):** построить CRM-работу вокруг внутреннего чата. **1 клиент = 1 чат**, возможно с вкладками. В сайдбарах — основные задачи, показатели, поручения (и др.).

**Принцип:** end-to-end сценарий JTD по клиенту в одном окне. Протокол → задача → поручение → показатель собираются в единую ленту диалога клиента (как system-карточки в чате, по аналогии с task-created карточками в ProjectChat).

**Макет (отдельная верстка):** `/dev/crm-chat` — `src/pages/dev/CrmChatDemo.tsx` (фейковые данные, ничего не пишет в БД). Трёхпанельный мессенджер-лейаут:
- **Левая панель:** список клиентов = список чатов (аватар/эмодзи, ранг A/B/C, стадия воронки, последнее сообщение, непрочитанные).
- **Центр:** шапка клиента + вкладки **Обсуждение / Задачи / Показатели / Поручения**. В «Обсуждении» — переписка + system-карточки (Создана задача, Поручение, Показатель, Протокол). Композер с подсказкой `/задача`, `/поручение`.
- **Правый сайдбар:** карточка клиента, контакты, прогресс по воронке, плитки показателей, основные задачи, поручения, документы.

**Связь с существующим:** переиспользует данные CRM (`clients`: territory/rank/retail_type/manager, воронка CRM_STAGES kp→samples→os→negotiation→shipping) и паттерн чата (`group_messages`, ProjectChat system-карточки, delegation 1 уровень).

**Статус:** ⏸ концепт-верстка готова, ждём решение Артёма по объёму реализации (реальные данные, схема привязки чата к клиенту, набор показателей).
