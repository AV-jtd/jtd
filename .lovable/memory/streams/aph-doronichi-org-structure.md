# АПХ Дороничи — оргструктура и иерархия

Отдельный стрим: описать полную организационную структуру АПХ Дороничи и связать с тегами `department` в JTD. Артём пришлёт документ со структурой.

## Что уже известно (на 19.04.2026)

### Head-of, которые УЖЕ есть в JTD (приглашать не надо)
- **Продакт** — директор + замы по площадкам (КМ/ФЗ/АА)
- **Реклама**
- **Закупки**
- **Продажи** — директор + замы по площадкам (КМ/ФЗ/АА), та же модель что и у Продакта
- **Планирование**
- **Аналитика**

### Модель «директор + замы по площадкам»
Применяется к **Продакту** и **Продажам**:
- Один директор отдела (head-of в JTD)
- Замы по каждой площадке: КМ, ФЗ, АА (пока разные люди)
- Назначение: задача с тегом `Продакт` + `КМ` уходит на зама КМ, директор видит все

**Открытый вопрос**: как технически реализовать?
1. Вариант A: один тег «Продакт» + фильтрация по площадке через тег `site`
2. Вариант B: отдельные теги «Продакт КМ / Продакт ФЗ / Продакт АА» (как сделано с ОКК)
3. Вариант C: иерархия тегов — родитель «Продакт» с подтегами по площадкам

Решение отложено до получения структуры от Артёма.

### Head-of, кого ещё нет в JTD (надо приглашать)
- RnD
- СКК
- Производство
- Покупка оборудования
- ОКК КМ / ОКК ФЗ / ОКК АА
- Замы Продакта/Продаж по площадкам (если будут отдельными аккаунтами)

## Что нужно от Артёма

1. Полная орг-структура АПХ Дороничи (документ или схема)

3. Подтверждение модели «директор + замы по площадкам» для Продакта и Продаж
4. Решение по варианту тегирования (A/B/C выше)
5. Замещающие на случай отпуска
