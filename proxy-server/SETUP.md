# Установка прокси-сервера на Windows

## Шаг 1 — Установить Node.js

1. Открой браузер, зайди на **https://nodejs.org**
2. Нажми большую зелёную кнопку **«LTS»** — скачается установщик
3. Запусти скачанный файл, нажимай «Далее» везде (настройки по умолчанию)
4. После установки **перезагрузи компьютер**

---

## Шаг 2 — Получить ключ OpenRouter

1. Зайди на **https://openrouter.ai** → Sign Up (можно через Google)
2. Зайди в **Keys** → **Create key** → скопируй строку вида `sk-or-...`
3. Пополни баланс на $5 (хватит надолго: категоризация 13 000 писем ≈ $3–8)

---

## Шаг 3 — Создать файл .env

1. Скачай папку `proxy-server` из репозитория на компьютер
2. Открой блокнот (Notepad), вставь:

```
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-ВАШ_КЛЮЧ_СЮДА
```

3. Сохрани файл **рядом с `start-proxy.bat`** под именем `.env`
   - В блокноте: Файл → Сохранить как → имя файла: `.env` → тип: «Все файлы»

---

## Шаг 4 — Запустить

Дважды кликни **`start-proxy.bat`**

Если всё ок — увидишь:
```
🚀 JTD Proxy запущен на порту 3000
   Провайдер:    openrouter
   Ключ:         ✓ найден
   Модель fast:  google/gemini-flash-1.5
   Модель smart: anthropic/claude-sonnet-4.6
```

---

## Шаг 5 — Проверить

Открой в браузере: **http://localhost:3000/health**

Увидишь JSON с `"status": "ok"` и `"Ключ найден — AI готов к работе ✓"` — всё работает.

---

## Выбор моделей (необязательно)

Можно добавить в `.env` строки для управления моделями:

```
# Дешёвая модель для сортировки 13 000 писем
AI_MODEL_FAST=google/gemini-flash-1.5

# Умная модель для анализа, досье, обещаний
AI_MODEL_SMART=anthropic/claude-sonnet-4.6
```

Список доступных моделей с ценами: **https://openrouter.ai/models**

---

## Прокси должен быть запущен пока работаешь с аддином

Минимизируй окно — оно просто висит в фоне. Закрываешь Outlook — закрываешь и прокси.
