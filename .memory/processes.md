# Memory: processes
Updated: 2026-04-11

## Рекомендации по улучшению процессов

### 1. Процессы
- **Обязательные поля**: При создании задачи требовать ответственного и дедлайн (мягкое напоминание)
- **Definition of Done для NPD-гейтов**: Чек-лист обязательных условий для прохождения каждого гейта
- **Автоматические вехи**: Создавать вехи при переходе между гейтами NPD
- **Closure Result**: Требовать заполнение результата при закрытии задачи

### 2. Роли
- **Добавить роль `manager`**: Трёхуровневая система admin / manager / user
  - Manager видит аналитику своих проектов, может делегировать и утверждать задачи
  - Manager не имеет доступа к системным настройкам (как admin)
- **Текущая проблема**: 68% задач без ответственного — нет контроля назначений

### 3. Аналитика и дашборды
- **Дашборд загрузки команды**: Визуализация активных/просроченных задач по сотрудникам
- **Метрики эффективности**: Среднее время выполнения, % просрочки, загрузка

### 4. Коммуникации
- **@-упоминания в комментариях**: С push и Telegram-уведомлениями
- **Автоуведомления о просрочке**: Ежедневные напоминания ответственным

- 33 пользователя, 1262 задачи, 552 визита за 30 дней
- Completion rate: 32% (405 задач)
- 68% задач без ответственного, 55% без дедлайна
- Высоконагруженные исполнители: Катя Соколова (49% просрочка)
- Паттерны «Директоров»: Артём, Елизавета, Юлия
